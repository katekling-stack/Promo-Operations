How to create an order

Straight from the form: no Terminal, no plan file, no Slack. · ← All tools

Open the Campaign Plan Form
You need to be on the VPN. If you can't get in, ask Kate to add you.

1Fill out the form like you always do

Pick the region, then the campaign, and add the title, durations, flight dates and targeting.
  • Brand: the list only shows the right kind. A Kids campaign shows Kids brands and an adult campaign shows adult ones. If the brand is brand new, just type its name and the tool will create it.
  • Kids campaigns: pick the Kids audience (Older, Younger or both). Without it, no lines are built.
  • Exclude videos: use the video's ID from FreeWheel (Videos, then the ID column). Double-check every digit.
  • Add to existing IO: leave it blank for a new order. Only fill it in when you're adding lines to an IO that already exists.

2Press “Review & create in tool”

Nothing is created yet. You get a preview of exactly what would be built: the IO name, brand, dates, how many placements, and every tier's targeting. Open any placement to see the detail.
Need to change something? Use Back to the form to edit. Your entries come back.

3Read the review

  • Yellow alerts (Tier 1 audience): some shows don't have a segment for your region yet, so they won't be targeted. Press Download request list to get a CSV of the segments to ask for.
  • Red “Blocked”: none of your shows has a segment in this region, so Tier 1 would run across the whole platform. It can't be created until at least one segment exists. Send the request list, then come back.
  • “Audience data is incomplete”: it isn't your plan. Tell Kate.

4Create it

Under the review there's a Create in FreeWheel box. Type the IO name exactly as shown, then press the button. It takes a minute or two. Please press it once and wait.
Don't press it twice or refresh while it's working. The tool won't let a plan be created twice, but waiting is the easy way to keep things tidy.
When it's done you'll see the new IO id and how many placements were created, for example “Created IO 98378384: 6 of 6 placements”.

5Check it with QA

On the app's home page open QA an order, paste the IO id and run it. You're looking for 0 errors. Orders usually show “no active creatives” warnings right after creation, which is normal until the creatives are attached.

If you see a message

It saysWhat it means / what to do
Blocked: no audience segment for any showRequest a segment for at least one show (use the request list), then review again.
An IO with this name already existsSomeone (maybe you) already created it. Put that IO's id in Add to existing IO to add lines to it.
These ‘Exclude videos’ ids don't existA video ID has a typo. Nothing was created. Fix the ID and try again.
Brand changed to match the campaignYou picked a brand from the other advertiser, so the tool used the matching one. Just letting you know.
Created IO… with fewer placements than expectedThe page lists which lines failed and why. Don't create again. Fix the cause and add the missing lines with Add to existing IO.
Another order is being createdSomeone else is mid-create. Wait a minute and try again.
Creating orders is switched offAsk Kate. It's a setting on the app.

Orders are created as drafts (not booked), under the shared tool login, with you named as trafficker. Anything odd? Send Kate the IO id and what you expected.
