Promo-Ops QA Tool: Setup Guide (Mac)

This sets up the promo-ops tool on your computer so you can check a FreeWheel order before it goes live. You give it an Insertion Order (IO) number and it reports anything that looks wrong. It only reads from FreeWheel. It never changes anything.

Plan on about 15 minutes. You only do this once. Copy and paste each command (the lines in typewriter-style text) into Terminal and press Enter.

Before you start

  • A GitHub account that has access to the cbsi-adtech/digital_promo_automation repo.
  • Your FreeWheel API login (username and password), the same one Ad Ops already uses for this tool. Ask whoever sent you this guide. Please don't email the password in plain text.
  • Windows instead of Mac? Use PowerShell, type python instead of python3, and follow docs/INSTALL_CHECKLIST.md inside the downloaded folder.

Step 1: Open Terminal and check Python

Press Cmd + Space, type Terminal, press Enter. Then run:

python3 --version

If it says Python 3.10 or higher, you're set. If not, download Python from python.org/downloads, install it, and run the command again.

Step 2: Make a GitHub token

The code is private, so GitHub won't accept your normal password on the command line. It needs a token instead.

  1. Go to github.com and click your profile picture (top right), then Settings.
  2. In the left menu, scroll to the bottom and click Developer settings.
  3. Click Personal access tokens, then Tokens (classic).
  4. Click Generate new token, then Generate new token (classic).
  5. Name it (for example "Promo-Operations"), pick an expiration, and tick the repo box.
  6. Click Generate token, then copy the token right away (it starts with ghp_). GitHub only shows it once. Save it in your password manager.
  7. Important: on the token list, click Configure SSO next to your new token, then Authorize next to cbsi-adtech. Without this step the download in Step 3 will be refused.

Never paste your token into a chat or email.

Step 3: Download the code

This puts a folder called Promo-Operations in the folder Terminal is currently in. To put it on your Desktop, first run cd ~/Desktop.

git clone https://github.com/cbsi-adtech/digital_promo_automation.git Promo-Operations

When it asks for a Username, type your GitHub username. When it asks for a Password, paste your token (not your GitHub password). Nothing shows on screen as you paste. That's normal.

Step 4: Go into the folder

cd Promo-Operations

(If you used the Desktop tip, it's cd ~/Desktop/Promo-Operations.) Every command below must be run from inside this folder.

Step 5: Install the tool

python3 -m pip install -e .

It prints a lot of lines. That's normal. When it finishes, check it worked:

promo-ops --help

You should see a list of commands.

Step 6: Add your FreeWheel login

Make your own settings file from the template:

cp .env.example .env

Open it in TextEdit:

open -e .env

Fill in FREEWHEEL_USERNAME and FREEWHEEL_PASSWORD with your FreeWheel API login. Make sure FREEWHEEL_NETWORK_ID=520311. Leave everything else as it is, then save and close. Never share or email this file. It contains your password.

Step 7: Check everything is connected

promo-ops doctor

You should see a green check for each item. If the only problem is about "MRM" and you only plan to run QA, that's fine.

Step 8: Run a QA check

Find the IO number in the FreeWheel address bar. It's the number after insertion_order_id=. Then run:

promo-ops qa 86085716

(Use your own IO number.) Useful extras:

  • Only look at the current season: add --only "Season 4" to the end.
  • Save a shareable report: add --out qa.md to the end.

How to read the results:

  • error: almost certainly wrong. Fix it before going live.
  • warn: likely wrong. Take a look.
  • info: the tool couldn't read that field. Check it by hand in FreeWheel.
  • ok: checked and correct.

The tool is new. A warning is a prompt to look, not always a real mistake. If something seems off, ask before changing anything.

Getting updates later

From inside the Promo-Operations folder, run:

./update.sh

It downloads the latest version of the tool. It replaces any changes you've made inside the folder, so don't edit files there.

If something goes wrong

  • "Password authentication is not supported": you typed your GitHub password. Paste the token instead.
  • "organization has enabled or enforced SAML SSO" or a 403 error: the token isn't authorized yet. Do the Configure SSO part of Step 2.
  • "Repository not found": your GitHub account doesn't have access yet. Ask whoever sent you this guide.
  • "command not found: promo-ops": run Step 5 again from inside the folder. If it still fails, close Terminal, reopen it, and cd back into the folder.
  • "command not found: python3": install Python (Step 1).
  • A login or 401 error from FreeWheel: reopen .env and re-check your username, password, and network ID.
