1 Create an order (Campaign Managers)

  1. Open the form: promo-ops-tools.skydancepages.cloud/form. If you see a yellow “This is an old copy of the form” bar, use the link in it.
  2. Fill it out.
    • Region, then Campaign. That sets the brand, advertiser and default products.
    • Brand (IO-level): pick one from the list, or type a new name and the tool creates it. The list only shows the right kind for your campaign: Kids brands for Kids campaigns, adult brands for adult ones.
    • Promoted title, durations, flight dates and targeting (showlist, genres, audience segments, Pluto categories and channels). The ✨ Suggest targeting button can propose targeting for a title.
    • Kids campaigns: pick the Kids audience (Older, Younger or both). Without it, no lines are built.
    • Exclude videos: use the video’s ID from FreeWheel (Videos, then the ID column). Check every digit.
    • Add to existing IO: leave blank for a new order. Fill it in only to add lines to an IO that already exists.
  3. Press “Review & create in tool.” Nothing is created yet. You get a preview of the IO name, brand, dates, number of placements and every tier’s targeting. Need to change something? Back to the form to edit brings your entries back. Download plan file saves your answers as a file you can keep or load later with Load a saved plan. You don’t need it to create an order.
  4. Read the review.
    • Yellow alerts (Tier 1 audience): some shows have no segment for your region yet, so they won’t be targeted. Press Download request list for a CSV of the segments to ask for.
    • Red “Blocked”: none of your shows has a segment in this region, so it can’t be created yet. Send the request list, and come back once at least one segment exists.
  5. Create it. Type the IO name exactly as shown, then press Create in FreeWheel. It takes a minute or two. Press it once and wait. When it finishes you get the new IO id and “X of Y placements.”
  6. Hand off. In the linked Salesforce case, mark the Case Status as Ready for Automation. Ad Ops then QA’s the IO, and you review and book it in FreeWheel.

Blocked: no audience segment for any showRequest a segment for at least one show (use the request list), then review again.
An IO with this name already existsIt was already created (maybe by you). Put that IO’s id in Add to existing IO to add lines to it.

Another order is being createdSomeone is mid-create. Wait a minute and try again.
Audience data is incompleteNot about your plan. Tell Kate.

2 QA an order before it goes live

Open QA an order, paste the IO id (the number the create step gave you, or the one in the FreeWheel URL: …insertion_order_id=80271357…), and run it. Up to 5 at a time. It only reads FreeWheel; nothing is changed. Copy report gives you a shareable version for the case or Slack.

Tick Include placements that already finished only when you want old lines checked too. Right after creation you’ll usually see “no active creatives” warnings. That’s normal until the creatives are attached.

What it checks — every placement

  • Ad units — correct group for the brand+format; pre-roll dropped at :30+; bumper units; never empty.
  • Creative duration — the creative length matches the duration the line is named for.
  • Time zone — the schedule is in the market’s time zone.
  • Targeting / relationships — right main inventory; no Pluto in no-Pluto regions; Samsung excluded for Pluto TV brands; Recommended Show only on P+/Pluto TV; AU Tier 4 UFC set present.
  • Frequency caps — order-level (per region) + placement-level (per tier).
  • Priority / precedence, naming, and geo.

How to read the report

TagMeaning
❌ errorAlmost certainly wrong — fix before going live.
⚠️ warnLikely wrong — check it.
ℹ️ infoCouldn’t read that field from FreeWheel — verify by hand.
✅ okVerified correct.

The summary line gives the error/warning count. 0 errors = the structure matches what the tool would have built. Fix any ❌, then tell the CM the draft is ready to review and book.

For Ad Ops and admins: Terminal tools (backup path)

Nobody needs this to create or QA orders anymore. It’s here for batches, for working outside the app, and as a fallback. Runs in Terminal on your own computer, from inside the Promo-Operations folder.

1 Set up the tool on your computer

You don’t copy files from someone else’s computer. Everyone downloads (“clones”) the same code from the shared GitHub repo — the single source of truth. Your .env (the FreeWheel login) is personal and never stored in GitHub; you create it once on your own machine.

Do this once (~15–20 min, copy/paste — no coding). Full details: docs/CLONE_SETUP.md.

  1. Get repo access — the code is in the private Paramount GitHub repo cbsi-adtech/digital_promo_automation. You need a GitHub account that is a member of the cbsi-adtech organization (ask Kate / your GitHub org admin), and you click Authorize for its single sign-on the first time GitHub asks.
  2. Install Python 3.10+ — from python.org (on Windows tick “Add Python to PATH”).
  3. Install Git — Mac: git --version (click Install if prompted); Windows: git-scm.com.
  4. Sign in to GitHub — easiest is the GitHub CLI: 
    gh auth login          # choose GitHub.com → HTTPS → Login with a browser
    Or install GitHub Desktop and sign in there.
  5. Clone the code (the main branch) into an easy spot (e.g. Desktop): 
    cd ~/Desktop
git clone --branch main \
  https://github.com/cbsi-adtech/digital_promo_automation.git Promo-Operations
cd Promo-Operations
  6. Create your .env (your FreeWheel login — the same AdOps.api@520311 access Ad Ops already uses): 
    cp .env.example .env    # Windows: copy .env.example .env
    Open .env and fill in FREEWHEEL_NETWORK_ID, FREEWHEEL_USERNAME, FREEWHEEL_PASSWORD. Never share or commit this file.
  7. Install the tool: 
    python -m pip install -e .   # Mac: python3 -m pip install -e .
  8. Test it: promo-ops --help should list the commands.
Keep it up to date anytime with ./update.sh — it pulls the latest tool + form. Because it hard-resets to the shared branch, don’t hand-edit files in this folder (only your git-ignored .env is left alone).

Path B  A batch (many at once)

Campaign Managers click Copy row for Sheet and paste into the shared Google Sheet. When it’s time:

File → Download → Comma-separated values (.csv)            # in the Google Sheet
promo-ops batch ~/Downloads/promo-batch.csv --out results.csv         # preview ALL rows
promo-ops batch ~/Downloads/promo-batch.csv --live --out results.csv  # push ALL drafts

results.csv maps each Salesforce Case # to its FreeWheel draft link + status.

Golden rules: always run the preview / no---live version first · re-running is safe (existing drafts are reused, never duplicated) · if a command says “does not exist,” you’re not in the folder — run cd ~/Desktop/Promo-Operations first.

QA from Terminal

promo-ops qa 80271357                  # review one IO
promo-ops qa 80271357 96525273         # several at once
promo-ops qa 80271357 --out qa.md      # + a shareable report file (paste in Slack / the case)
promo-ops qa 80271357 --only "Tier 4"  # focus on certain placements
The IO id is the number in the FreeWheel URL: …insertion_order_id=80271357…
