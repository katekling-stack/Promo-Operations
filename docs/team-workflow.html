Promo Ops — Creating FreeWheel Drafts

Team guide · Fill the form → build the draft in FreeWheel → a Campaign Manager reviews & books it.

The one thing to remember: this tool only ever creates a NOT_BOOKED draft — nothing goes live/serves until a Campaign Manager books it in FreeWheel. You’re always just “sending the draft over.”

2 Everyday use — pick a path

Use Path A for one campaign, Path B for a batch of them. Both create the same kind of draft — Path B just handles a whole list at once.

Path A  One campaign

Campaign Manager

  1. Open the form: templates/campaign-plan/campaign-plan-form.html (double-click it).
  2. Fill it in — Region, Campaign, Promoted Title, durations, flight, targeting.
  3. Click Download plan file → a …plan.json saves to Downloads.
  4. Post that plan file to the Slack channel #promo-order-automations-submissions.

Ad Ops — grab the plan file from #promo-order-automations-submissions (download it to your Downloads folder), then in Terminal:

# be in the project folder first
cd ~/Desktop/Promo-Operations

# 1) sanity-check (creates nothing)
promo-ops preview  ~/Downloads/tulsa-king-usa.plan.json

# 2) push the NOT_BOOKED draft to FreeWheel
promo-ops push     ~/Downloads/tulsa-king-usa.plan.json --target freewheel --live

💡 Don’t type long file paths. Type promo-ops push (with a space), then drag the file from Finder onto the Terminal window — it fills in the path — then add --target freewheel --live and press Return.

Then tell the CM the draft is in FreeWheel for review.

Path B  Many at once (the batch sheet)

Campaign Manager — for each campaign:

  1. Fill the form.
  2. Click Copy row for Sheet (copies one row).
  3. Open the shared team Google Sheet → next empty row → paste (⌘V). (Simple campaigns can be typed straight into the sheet.)

Ad Ops — when it’s time to push the batch:

  1. In the Google Sheet: File → Download → Comma-separated values (.csv) (saves to Downloads).
  2. In Terminal:
cd ~/Desktop/Promo-Operations

# preview ALL rows (creates nothing)
promo-ops batch  ~/Downloads/promo-batch.csv --out results.csv

# push ALL the drafts
promo-ops batch  ~/Downloads/promo-batch.csv --live --out results.csv

results.csv lists every case with its FreeWheel draft link + status — paste it back onto the cases so the CM knows what to review.

💡 You give the tool the file (drag it onto Terminal). You never copy rows out of the sheet into the terminal.

4 Golden rules

  • Always preview / dry-run first (leave off --live) and eyeball the placements.
  • --live = “push the real draft.” It does not book or serve anything — every draft is NOT_BOOKED until a CM books it in FreeWheel.
  • Re-running is safe. Fix a couple rows and run again — existing drafts are reused, never duplicated.
  • If a command says “does not exist,” you’re probably not in the folder — run cd ~/Desktop/Promo-Operations first. Your prompt shows Promo-Operations % when you’re in the right place.

6 If something looks off

You see…Do this
command not found: promo-opsYou’re not in the folder, or it isn’t installed — see the setup guide below.
… does not existRun cd ~/Desktop/Promo-Operations first, or drag the file onto Terminal.
A login / 401 error on pushRe-open .env and check the FreeWheel username/password.
“… matched no FreeWheel Video Series/Attribute”That value isn’t in FreeWheel’s list — check the spelling, or the CM adds it by hand. The rest of the draft still builds.
Nothing seems to happen after a live pushIt’s working quietly — give it up to a minute; it prints the result when done.

＋ First-time setup (once per computer)

New teammate getting set up? Full step-by-step (install Python, get the code, add the FreeWheel login) is in docs/INSTALL_CHECKLIST.md. The short version:

cd ~/Desktop/Promo-Operations
python3 -m pip install -e .          # install the promo-ops command
cp .env.example .env                 # then add FreeWheel username/password
open -e .env

FreeWheel access uses a dedicated API user (e.g. AdOps.api@520311) — your personal SSO login won’t work for the API. Ask your FreeWheel admin for it.
